# Virtual Reality City Simulation

**Built with Unity (Version 2022.3.3f1)**

![VR City Simulation](https://github.com/user-attachments/assets/08d4f326-7f73-4821-9735-34f0aa401d3a)

## Features
- **Traffic Interactions**: Vehicles and pedestrians dynamically interact with traffic systems
- **Vehicle Acceleration & Deceleration**: Smooth vehicle movements 
- **Spatial Sound**: 3D sounds for the environment
